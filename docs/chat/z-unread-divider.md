# z-unread-divider

The accented "New messages" line marking where unread messages begin in a
thread. Like [z-date-divider](z-date-divider.md) but toned to draw the eye.

```html
<z-unread-divider></z-unread-divider>
<z-unread-divider label="12 new messages"></z-unread-divider>
```

## Attributes

| Attribute | Values | Default | Description |
| --- | --- | --- | --- |
| `label` | string | `New messages` | divider text |
| `tone` | `secondary` | primary | accent color |
| `is-hidden` | boolean | — | hide |
